Достигатор v2 r3 — локальная подготовка, не активирована.

Запуск из этой папки, Node.js 22+, без установки зависимостей:
  node --test model.test.mjs local-integration.test.mjs
  node serve.mjs
Открыть http://127.0.0.1:4189/
Остановка: Ctrl+C. Сервер слушает только 127.0.0.1.

program.json — новая редакция, уточнение и несогласованная замена.
revisions/ — неизменённая предыдущая редакция черновика.
model.mjs — проверка ограничений, план, оценка времени, сопоставимость.
local-integration.mjs — подготовка неизменяемого снимка дня, без активации, истории, сети или записи фактов.
index.html, app.mjs, style.css — автономный предпросмотр.
samples/ — локальные снимки A/B/C без фактических результатов.
report.txt — уточнения, граница готовности и совместимость.
verification.txt — результаты проверок этой редакции.

Выбор на экране не сохраняется после перезагрузки. Кнопка «Скачать снимок для проверки» сохраняет отдельный JSON; он не импортируется в действующее приложение и ничего не активирует. Замены на согласовании отсутствуют; в среду сохранён подъём гантелей в стороны.

Облачные инструменты не используются. В src или базу ничего копировать не нужно.
