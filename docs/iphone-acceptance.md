# Приёмка «Достигатора» V2.1 на физическом iPhone

Статус: НЕ ВЫПОЛНЕНА. Эмуляция, браузер Mac и localhost PWA не заменяют эту приёмку.

Дата: 23.10.2026. Проверять точный commit из отчёта; production не изменять.

Доступный отдельный стенд: http://192.168.1.125:4218/training (одна Wi-Fi-сеть с Mac).
Настоящий backend: xorlzijpgklasatxzcnn.supabase.co. Только синтетические данные.
Вход: приватные одноразовые тестовые учётные данные, не включённые в Git. Не вводить production-пароль.
Mac должен быть включён, процесс предпросмотра — запущен. IP после переподключения Wi-Fi может измениться.

HTTP LAN позволяет проверить интерфейс, вход и запись, но НЕ доказывает автономный холодный запуск PWA. Для полного цикла нужен отдельный доверенный HTTPS-адрес. Публикация или настройка доверия сертификату согласуется отдельно; браузерные предупреждения автоматически не обходились.

Перед тестом:
- Записать модель iPhone, iOS, Safari, время, commit, URL, режим Safari/«На экран Домой».
- На существующем production-origin ничего не очищать и не переустанавливать. Зафиксировать активный черновик, очереди, кардио и незавершённый ввод отдельно в Safari и существующей PWA. На Mac через Safari Web Inspector можно сделать приватную копию localStorage; не выгружать sb-* токены и не пересылать копию третьим лицам.
- Убедиться, что резервная копия читается. Переносить только копию, сохраняя исходные ключи. История Supabase не является копией локального черновика.
- Использовать одноразовые тестовые аккаунты A/B в независимом проекте.
