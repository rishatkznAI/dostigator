# Мобильный UX-аудит «Достигатора» — 23.10.2026

## Уровни подтверждения
- Подтверждено двумя скриншотами iPhone: действующая тренировка A V2.1, красная панель конфликта тренировки B, ввод подходов, непонятные скрытые действия.
- Проверено по исходникам: маршруты, навигация, карточка подхода, CSS конфликтов силовой/кардио, тренерские рекомендации.
- CI: pnpm test:all (lint, TS, Vitest, программа, PostgreSQL, build). Фактический результат привязать к SHA PR.
- Не подтверждено: полный визуальный проход всех экранов на реальном iPhone Safari/PWA с клавиатурой, крупным текстом, VoiceOver и в альбомном режиме.

## Матрица визуальной приемки — не проведена
Для каждого экрана: ширины 320/375/390/430/768 CSS px, портрет и альбом, клавиатура открыта, крупный шрифт, прокрутка, горизонтальный overflow = 0, активность каждой кнопки, тексты ошибок.

## Gate перед выпуском
1. CI по актуальному SHA PR зелёный. 2. Реальный iPhone: проверить исправленные карточки, поля и отсутствие горизонтального скролла без удаления данных. 3. Скриншоты до/после. 4. Полный iPhone gate в docs/iphone-acceptance.md. 5. Лишь затем merge в main, который запускает GitHub Pages deploy.

Не утверждать, что весь интерфейс проверен визуально только по зелёным unit-тестам; не сбрасывать production/хранилище для устранения UI багов.
