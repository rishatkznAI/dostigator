Достигатор — локальная интеграция 22.10.2026

РЕАЛИЗОВАНО
- Каноническая cardio_facts: точные секунды 1..86459, явная nullable-связь с силовой того же владельца, настройки, серверная ревизия и tombstone. Отдельное кардио допустимо.
- Старые целые минуты читаются с неизвестной точностью. Массового backfill и привязки по дате нет. Старые записи не переписаны миграцией.
- Для новых фактов от минуты поддерживается legacy-проекция с тем же UUID; двойного учёта нет. Записи <60 секунд остаются точными и доступны новому API; старый клиент их не покажет. Прямые записи старых клиентов в уже переведённые факты блокируются.
- RPC кардио сохраняет весь факт атомарно. mutation UUID и сохранённый ответ защищают повтор после timeout-after-commit; expected revision защищает конфликт. Очередь удаляется после проверки точного ответа, а не после произвольного HTTP-успеха.
- Подтверждённые локальные receipts переносятся только при совпадении версии; сервер проверяет исходный legacy updated_at. При конфликте локальный ввод остаётся для сравнения. Явное снятие связи/очистка метрик не восстанавливает старые sidecar-значения.
- Короткое кардио записывается без округления до минуты. Секунды отображаются в результате, истории, силовом итоге и недельных суммах.
- Резервная копия кардио в интерфейсе включает точность, связь, настройки и удаления. Восстановление атомарно, только для того же владельца, только недостающие или идентичные факты; при расхождении откатывается целиком. Сохраняется исторический created_at. Связанная силовая должна уже существовать. Это отдельная копия кардио; существующий экспорт планировщика не выдаётся за резервную копию всей тренировки.
- Силовая сохраняется одним RPC: сессия, упражнения, подходы, удаления. RIR NULL сохраняется. Завершённая сессия не открывается запоздавшим active; отменённая не воскресает. Очередь не удаляет новый локальный снимок по подтверждению старого.
- При первом переходе существующей активной силовой с legacy API и при конфликте ревизий требуется сравнение. Можно скачать ввод, явно выбрать свою версию либо оставить серверную. Чужую/завершённую серверную запись нельзя перезаписать этим действием. Отмена не скрывает черновик при отказе сервера или наличии связанного кардио.
- Шесть исходных API-тестов поддерживают современный publishable key и проверяют gateway/Auth перед негативными запросами: неверный ключ больше не выдаёт ложное подтверждение запрета доступа.
